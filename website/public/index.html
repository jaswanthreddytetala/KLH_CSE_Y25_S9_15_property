About Property Finder

Making property search simple, transparent, and efficient.

Property Finder helps buyers, renters, and investors discover relevant homes through intuitive search, category filters, location insights, and property comparison tools.

Behind the scenes, the Java implementation preserves the original corpus and algorithmic search foundation used for pattern matching, ranking, filtering, and recommendation support.

Technical details

  • Java-based string matching and search logic for property corpus analysis
  • Ranking and filtering support using algorithmic heuristics and optimization methods
  • Dynamic programming and network flow ideas used for structured optimization
  • Approximation and randomized strategies for scalable property recommendation

Algorithms in the backend: KMP, Z Algorithm, Rabin-Karp, DP, flow optimization, approximation, randomized, and parallel techniques.

These are documented for viva and academic review, while the end-user experience remains focused on buying, renting, comparing, and viewing properties.
